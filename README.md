# 🎥 cam-to-ascii  
**Live Camera to ASCII Art Converter**

[🌐 Try it Live](https://fbn776.github.io/cam-to-ascii/)

This is a fun and lightweight JavaScript project that captures your webcam feed and converts it into animated ASCII art in real time — all in your browser!

## ✨ Features
- Real-time webcam capture
- ASCII character mapping based on brightness
- No backend or server needed — runs entirely in your browser
- Minimal HTML, CSS, and JavaScript

## 🚀 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/fbn776/cam-to-ascii.git
cd cam-to-ascii
```

### 2. Open `index.html` in your browser  
Or simply [try the live version](https://fbn776.github.io/cam-to-ascii/).
